2. 题意简述 (Problem Summary)

给定 nnn（nnn 为偶数，2≤n≤1052 \le n \le 10^52≤n≤105）个新成员，每人对 333 个部门的满意度 ai,j∈[0,2×104]a_{i,j} \in [0, 2 \times 10^4]ai,j​∈[0,2×104]。为每个成员选择恰好一个部门 di∈{1,2,3}d_i \in \{1,2,3\}di​∈{1,2,3}，最大化满意度之和 ∑i=1nai,di\sum_{i=1}^{n} a_{i,d_i}∑i=1n​ai,di​​，且每个部门分配人数不超过 n2\frac{n}{2}2n​。多组测试数据，t≤5t \le 5t≤5。

3. 朴素解法 (Brute-Force)

最直接的想法是枚举每个成员的部门选择，共 3n3^n3n 种方案，对每种方案检查容量约束并计算满意度。n=10n = 10n=10 时约 6×1046 \times 10^46×104 种，可过测试点 1∼41 \sim 41∼4；n≥30n \ge 30n≥30 时 330≈2×10143^{30} \approx 2 \times 10^{14}330≈2×1014，完全不可行。

另一种思路是 DP：设 dp[i][c1][c2]dp[i][c_1][c_2]dp[i][c1​][c2​] 表示前 iii 人中部门 111 有 c1c_1c1​ 人、部门 222 有 c2c_2c2​ 人时的最大满意度（部门 333 人数为 i−c1−c2i - c_1 - c_2i−c1​−c2​）。状态数 O(n3)O(n^3)O(n3)，n=105n = 10^5n=105 时约 101510^{15}1015，同样不可行。瓶颈在于容量约束使得状态空间与 nnn 的幂次绑定，无法线性递推。

4. 核心解法 (Main Solution)

特殊性质

本题的关键观察在于 333 个部门的容量约束具有特殊的结构。设 cntj\text{cnt}_jcntj​ 为部门 jjj 分配到的人数，则 cnt1+cnt2+cnt3=n\text{cnt}_1 + \text{cnt}_2 + \text{cnt}_3 = ncnt1​+cnt2​+cnt3​=n，每个 cntj≤n2\text{cnt}_j \le \frac{n}{2}cntj​≤2n​。

至多一个部门超员：若两个部门同时超员（各 >n2> \frac{n}{2}>2n​），则总人数 >n> n>n，矛盾。因此，无约束贪心解中至多有一个部门违反容量约束。

关键突破

从 3n3^n3n 的枚举瓶颈出发，利用「至多一个部门超员」这一性质，将问题分解为两步：

  1. 贪心：忽略容量约束，每个成员选满意度最高的部门，得到无约束最优解 sum\text{sum}sum。
  2. 反悔：若唯一超员部门 mmm 有 cntm>n2\text{cnt}_m > \frac{n}{2}cntm​>2n​，将 cntm−n2\text{cnt}_m - \frac{n}{2}cntm​−2n​ 人从部门 mmm 改派到各自的次优部门，使容量满足约束。

推导过程

下面推导反悔策略的正确性。

改派人数：部门 mmm 超员 cntm−n2\text{cnt}_m - \frac{n}{2}cntm​−2n​ 人，需恰好移出这么多。不能多移（不必要损失），不能少移（仍超员）。

改派目标：每个被移出的人应去自己的次优部门（满意度第二高的部门），而非第三优部门。因为次优满意度 ≥\ge≥ 第三优满意度，改派到次优的损失 ≤\le≤ 改派到第三优的损失。

次优部门不会超员：设其余两个部门共有 n−cntmn - \text{cnt}_mn−cntm​ 人。最坏情况下所有被改派的人都去同一个次优部门，该部门人数上界为：

(n−cntm)+(cntm−n2)=n−n2=n2(n - \text{cnt}_m) + \left(\text{cnt}_m - \frac{n}{2}\right) = n - \frac{n}{2} = \frac{n}{2} (n−cntm​)+(cntm​−2n​)=n−2n​=2n​

恰好等于容量上界，不会超员。

选损失最小的人改派：每个被改派成员 iii 的损失为 ai,max⁡−ai,suba_{i, \max} - a_{i, \text{sub}}ai,max​−ai,sub​（最优满意度与次优满意度之差）。将超员部门的成员按此损失升序排序，取前 cntm−n2\text{cnt}_m - \frac{n}{2}cntm​−2n​ 个改派，总损失最小。

最终答案为：

ans=sum−∑改派的 k 人(ai,max⁡−ai,sub)\text{ans} = \text{sum} - \sum_{\text{改派的 } k \text{ 人}} \left(a_{i, \max} - a_{i, \text{sub}}\right) ans=sum−改派的 k 人∑​(ai,max​−ai,sub​)

其中 k=cntm−n2k = \text{cnt}_m - \frac{n}{2}k=cntm​−2n​，取损失最小的 kkk 人。

5. 正确性证明 (Proof of Correctness)

下面我们总结一下贪心策略的证明要点，共证明了三点：贪心解的无约束最优性、反悔策略的充分性、次优部门的安全性。

引理 1（贪心最优）：无容量约束时，每个成员独立选择满意度最高的部门，满意度之和取到全局最大。这是因为 ∑i=1nai,di\sum_{i=1}^{n} a_{i,d_i}∑i=1n​ai,di​​ 中各项独立，max⁡di∑ai,di=∑max⁡diai,di\max_{d_i} \sum a_{i,d_i} = \sum \max_{d_i} a_{i,d_i}maxdi​​∑ai,di​​=∑maxdi​​ai,di​​。

引理 2（至多一个超员部门）：若部门 jjj 与 j′j'j′ 同时超员，cntj+cntj′>n\text{cnt}_j + \text{cnt}_{j'} > ncntj​+cntj′​>n，但 cnt1+cnt2+cnt3=n\text{cnt}_1 + \text{cnt}_2 + \text{cnt}_3 = ncnt1​+cnt2​+cnt3​=n，矛盾。故至多一个部门超员。

引理 3（次优部门安全）：改派 k=cntm−n2k = \text{cnt}_m - \frac{n}{2}k=cntm​−2n​ 人到次优部门后，任一次优部门的人数上界为 n2\frac{n}{2}2n​（见 §4 推导），不超员。

定理（反悔最优）：在全局贪心解的基础上，从唯一超员部门 mmm 移出恰好 kkk 人，每人移到次优部门，选损失最小的 kkk 人，所得方案是容量约束下的最优解。

设贪心解为 S∗S^*S∗（无约束最优），任一合法解 TTT 的满意度 ≤S∗\le S^*≤S∗（因为 S∗S^*S∗ 是无约束最大值）。合法解必须在 S∗S^*S∗ 基础上调整超员部门 mmm 的分配：将至少 kkk 人从部门 mmm 移出。每人移出后，去次优部门的损失 ≤\le≤ 去第三优部门的损失（ai,sub≥ai,thirda_{i, \text{sub}} \ge a_{i, \text{third}}ai,sub​≥ai,third​），故最优调整中每人都去次优部门。在所有「移 kkk 人到次优部门」的方案中，选损失最小的 kkk 人总损失最小。由引理 3，次优部门不超员，方案合法。因此该反悔策略得到的解是合法解中的最优。

综上所述，算法正确。

  • 时间复杂度：O(nlog⁡n)O(n \log n)O(nlogn)。每人对 333 个满意度排序 O(1)O(1)O(1)（常数大小），收集超员部门成员 O(n)O(n)O(n)，按损失排序 O(nlog⁡n)O(n \log n)O(nlogn)。n≤105n \le 10^5n≤105 时约 1.7×1061.7 \times 10^61.7×106 次运算，1s 内轻松通过。

  • 空间复杂度：O(n)O(n)O(n)。存储 nnn 个成员的满意度数组与临时向量，约几 MB，远低于 512 MB 限制。

9. 补充说明 (Additional Notes)

  • 题目渊源：本题出自 CSP-S 2025 第二轮，是「贪心 + 反悔」的经典入门题。这类「先贪心求无约束最优，再对违反约束的部分做最小代价调整」的思路在竞赛中很常见，核心识别信号是约束结构简单（如至多一个维度违约）、且调整代价可排序取最小。本题 333 个部门与 n2\frac{n}{2}2n​ 限制的设定使得「至多一个超员」这一性质很容易发现，是反悔策略成立的基础。
  • 数据范围与测试点：测试点按 nnn 规模分档，最小 n=2n = 2n=2（测试点 1），最大 n=105n = 10^5n=105（测试点 12 起）。特殊性质 A（仅部门 1 有满意度）和 B（仅部门 1、2 有满意度）是贪心 + 反悔的退化场景，C 为随机数据。O(nlog⁡n)O(n \log n)O(nlogn) 的排序解法可过全部测试点。
