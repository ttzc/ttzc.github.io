洛谷 P1048 采药 - Solution

1. 题目数据 (Problem Metadata)

  • 题目类型：传统题
  • 题目链接：https://www.luogu.com.cn/problem/P1048
  • 时间限制：1.00s
  • 内存限制：125.00MB

2. 题意简述 (Problem Summary)

给定总时间 TTT（1≤T≤10001 \le T \le 10001≤T≤1000）和 MMM 株草药（1≤M≤1001 \le M \le 1001≤M≤100）。每株草药 iii 需要采摘时间 tit_iti​ 且具有价值 viv_ivi​（1≤ti,vi≤1001 \le t_i, v_i \le 1001≤ti​,vi​≤100）。求在总时间不超过 TTT 的前提下，能够获得的最大总价值。

本质是 0/1 背包问题：MMM 个物品，背包容量为 TTT，物品 iii 重量 tit_iti​、价值 viv_ivi​，每个物品只能选一次，最大化总价值。

3. 朴素解法 (Brute-Force)

枚举每株草药的"采/不采"，共 2M2^M2M 种方案，对每种合法方案求和取最大。时间复杂度 O(2M)O(2^M)O(2M)。

本题 M≤100M \le 100M≤100，21002^{100}2100 远超任何实际时限，即使 M≤10M \le 10M≤10 的子任务（210=10242^{10} = 1024210=1024）勉强可过，但满数据下即使再怎么剪枝也完全不可行。需要更高效的做法。

4. 核心解法 (Main Solution)

  • 特殊性质：问题具有最优子结构——前 iii 个物品的最优解可由前 i−1i-1i−1 个物品的最优解递推得到。同时，状态转移仅依赖上一阶段，具有无后效性。因此可用动态规划求解。

  • 关键突破：将"枚举所有子集"转化为"按物品逐个决策"。设 dp[i][j]dp[i][j]dp[i][j] 表示考虑前 iii 株草药、总用时不超过 jjj 时的最大价值，则每次只需决定第 iii 株是采还是不采。

  • 推导过程：

    定义 dp[i][j]dp[i][j]dp[i][j] 为前 iii 株草药在总用时不超过 jjj 的条件下可获得的最大价值。

    不采第 iii 株：价值继承前 i−1i-1i−1 株的结果，dp[i][j]=dp[i−1][j]dp[i][j] = dp[i-1][j]dp[i][j]=dp[i−1][j]。

    采第 iii 株：需预留 tit_iti​ 的时间，dp[i][j]=dp[i−1][j−ti]+vidp[i][j] = dp[i-1][j - t_i] + v_idp[i][j]=dp[i−1][j−ti​]+vi​（前提 j≥tij \ge t_ij≥ti​）。

    两者取最大，得到状态转移方程：$$dp[i][j] = \max\big(dp[i-1][j],\ dp[i-1][j - t_i] + v_i\big) \quad (j \ge t_i)$$
    当 j<tij < t_ij<ti​ 时，无法采摘第 iii 株，dp[i][j]=dp[i−1][j]dp[i][j] = dp[i-1][j]dp[i][j]=dp[i−1][j]。

    空间优化（滚动数组）：观察转移方程，dp[i][⋅]dp[i][\cdot]dp[i][⋅] 仅依赖 dp[i−1][⋅]dp[i-1][\cdot]dp[i−1][⋅]，因此可以去掉第一维。但注意：更新 dp[j]dp[j]dp[j] 时需要用到旧的 dp[j−ti]dp[j - t_i]dp[j−ti​]（即上一轮的 i−1i-1i−1 状态），若 jjj 从小到大遍历，dp[j−ti]dp[j - t_i]dp[j−ti​] 可能已被本轮更新覆盖，导致同一物品被多次选用（变成完全背包）。因此必须 倒序 遍历 jjj（从 TTT 到 tit_iti​），保证 dp[j−ti]dp[j - t_i]dp[j−ti​] 仍是上一轮的值： $$dp[j] = \max\big(dp[j],\ dp[j - t_i] + v_i\big) \quad (j = T, T-1, \dots, t_i)$$
    使用奇偶法滚动数组优化也可，但本题使用倒序法更简单。
    初始 dp[0…T]=0dp[0 \dots T] = 0dp[0…T]=0，最终答案为 dp[T]dp[T]dp[T]。

5. 正确性证明 (Proof of Correctness)

最优子结构：假设前 iii 株草药、容量 jjj 的最优方案为 SSS。若 SSS 不包含第 iii 株，则 SSS 也是前 i−1i-1i−1 株、容量 jjj 的最优方案（否则可替换为更优方案）。若 SSS 包含第 iii 株，去掉它后得到前 i−1i-1i−1 株、容量 j−tij - t_ij−ti​ 的方案，该方案也必为最优（否则原方案非最优）。两种情况下子问题最优解均蕴含于原问题最优解中，满足最优子结构。

无后效性：将物品编号 iii 视为阶段，第 iii 阶段的状态仅由第 i−1i-1i−1 阶段转移而来，与 i+1i+1i+1 及之后的阶段无关。因此 DP 递推有效。

空间优化（倒序遍历）的正确性，上文已经证明。

6. 复杂度分析 (Complexity)

  • 时间复杂度：O(MT)O(MT)O(MT)。外层循环 MMM 次，内层循环至多 TTT 次，每次转移 O(1)O(1)O(1)。本题 M≤100M \le 100M≤100，T≤1000T \le 1000T≤1000，运算量约 10510^5105 级别，在年代久远的评测机上也可在 1 秒内完成。

  • 空间复杂度：一维优化后为 O(T)O(T)O(T)，即 dpdpdp 数组大小。本题 T≤1000T \le 1000T≤1000，占用内存约 4 KB，远小于通常的 128 MB 限制。

7. 实现细节与避坑指南 (Implementation Details)

  • 倒序遍历是核心：0/1 背包空间优化中，jjj 必须从大到小遍历。若写成正序 for (int j = 0; j <= T; j++)，等价于完全背包，每株草药可无限次采摘，答案必然错误。
  • 数组大小：dpdpdp 数组至少开到 Tmax⁡=1000T_{\max} = 1000Tmax​=1000，建议多开几个（如 100510051005），防止 off-by-one。
  • 初始化：全部赋 000 即可（不要求恰好装满，只要求不超过容量）。
  • 循环边界条件：注意 j >= t[i]，以防止数组越界问题。

9. 补充说明 (Additional Notes)
