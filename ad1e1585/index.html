2. 题意简述 (Problem Summary)

起点到终点距离为 LLL（1≤L≤1091 \le L \le 10^91≤L≤109），中间有 NNN 块岩石，第 iii 块距起点 DiD_iDi​（按升序给出）。至多移走 MMM（0≤M≤N≤500000 \le M \le N \le 500000≤M≤N≤50000）块岩石（不含起点和终点），求移走后最短跳跃距离的最大值：

ans=max⁡移走≤M块min⁡所有相邻跳跃距离\text{ans} = \max_{\text{移走} \le M \text{块}} \min_{\text{所有相邻跳跃}} \text{距离} ans=移走≤M块max​所有相邻跳跃min​距离

3. 朴素解法 (Brute-Force)

枚举从 NNN 块岩石中移走哪 MMM 块（或不移），对每种方案计算相邻跳跃距离的最小值，取所有方案中的最大值。

  • 方案数：(NM)\binom{N}{M}(MN​)，N=50000N = 50000N=50000 时完全不可行。
  • 20%20\%20% 数据 N≤10N \le 10N≤10，(105)=252\binom{10}{5} = 252(510​)=252，可过。

4. 核心解法 (Main Solution)

特殊性质

本题是经典的「最大化最小值」问题。设 f(x)f(x)f(x) 表示「能否通过移走 ≤M\le M≤M 块岩石，使最短跳跃距离 ≥x\ge x≥x」，则 fff 具有 二段性：若 f(x)f(x)f(x) 为真，则 ∀x′<x\forall x' < x∀x′<x，f(x′)f(x')f(x′) 也为真。这是因为同一组移走方案如果保证了最小距离 ≥x\ge x≥x，自然也 ≥x′\ge x'≥x′。则存在临界值 ans\text{ans}ans，使得 f(x)f(x)f(x) 在 x∈[0,ans]x \in [0, \text{ans}]x∈[0,ans] 恒真、x∈(ans,L]x \in (\text{ans}, L]x∈(ans,L] 恒假。

关键突破

从 (NM)\binom{N}{M}(MN​) 的枚举瓶颈出发，利用二段性（单调性）将「求最优解」转化为「判定某个 xxx 是否可行」。判定可以用 贪心 在 O(N)O(N)O(N) 内完成：从左到右扫描岩石，遇到与上一次落脚点距离 <x< x<x 的岩石就移走，否则保留并更新落脚点。这样移走的岩石数即为使最小距离 ≥x\ge x≥x 所需的最少移走数，与 MMM 比较即可判定。

5. 正确性证明 (Proof of Correctness)

二段性

上文“特殊性质”证明了这个问题具有二段性，所以二分算法正确。

贪心最优性

需证：上述贪心策略移走的岩石数是所有合法方案中的最小值。

设贪心保留的岩石位置为 g0=0<g1<g2<⋯<gkg_0 = 0 < g_1 < g_2 < \cdots < g_kg0​=0<g1​<g2​<⋯<gk​（g0g_0g0​ 为起点），任一合法方案保留的岩石位置为 o0=0<o1<⋯<ojo_0 = 0 < o_1 < \cdots < o_jo0​=0<o1​<⋯<oj​。合法意味着 oi+1−oi≥xo_{i+1} - o_i \ge xoi+1​−oi​≥x。

归纳证明 gi≤oig_i \le o_igi​≤oi​（∀i≤min⁡(k,j)\forall i \le \min(k, j)∀i≤min(k,j)）：

  • 基础：g0=0=o0g_0 = 0 = o_0g0​=0=o0​（起点必保留）。
  • 归纳：设 gi≤oig_i \le o_igi​≤oi​。贪心保留 gi+1g_{i+1}gi+1​ 为第一个满足 d≥gi+xd \ge g_i + xd≥gi​+x 的岩石。而合法方案中 oi+1≥oi+x≥gi+xo_{i+1} \ge o_i + x \ge g_i + xoi+1​≥oi​+x≥gi​+x，所以 oi+1o_{i+1}oi+1​ 本身就满足 d≥gi+xd \ge g_i + xd≥gi​+x，即 oi+1o_{i+1}oi+1​ 是一个候选位置。贪心取最早的候选，故 gi+1≤oi+1g_{i+1} \le o_{i+1}gi+1​≤oi+1​。

由 gi≤oig_i \le o_igi​≤oi​ 可知贪心保留的岩石数 k≥jk \ge jk≥j，即贪心移走的岩石数 N−k≤N−jN - k \le N - jN−k≤N−j。贪心移走数 ≤\le≤ 任一合法方案移走数，故为最小。

终点处理：循环结束后若 L−gk<xL - g_k < xL−gk​<x，需移走 gkg_kgk​。此时 L−gk−1=(L−gk)+(gk−gk−1)L - g_{k-1} = (L - g_k) + (g_k - g_{k-1})L−gk−1​=(L−gk​)+(gk​−gk−1​)，其中 gk−gk−1≥xg_k - g_{k-1} \ge xgk​−gk−1​≥x（贪心性质），故 L−gk−1≥xL - g_{k-1} \ge xL−gk−1​≥x，移走 gkg_kgk​ 即可，无需连锁移走。这样既能构造出一种合法方案，又保证需要移走的石头最少。

通俗地，核心思想非常简单：贪心算法从不回头。它每次都选第一个满足距离限制的石头落脚，把后面的路留到最长，因此它移走的石头数量自然就是最少的。

Bug 分析

  • Bug 描述：我最早实现的版本的 check 函数采用三趟扫描策略（起点侧 → 终点侧 → 中间贪心），因为当时没想到末端点怎么处理，没有证明出来贪心最优性的“终点处理”。其中第二趟和第三趟内层循环（具体见注释）在标记岩石时执行 flag[i] = 1, res++，均未检查 flag[i] 是否已为 1。当一块岩石被多趟扫描覆盖时（例如同时靠近起点和终点，或同时靠近终点和另一块保留的岩石），res 被重复累加，导致 res 虚高，check(x) 误返回 false，最终答案偏小。

  • 官方数据覆盖情况：代码通过了洛谷全部官方测试数据并 AC。两个 bug 的触发条件较为特殊（需要单块岩石同时满足两个距离约束），官方数据未覆盖。

  • Hack 数据：

    追踪：L=4,d1=2L=4, d_1=2L=4,d1​=2。check(3)\text{check}(3)check(3) 时，第一趟标记 d1=2<3d_1=2 < 3d1​=2<3（res=1\text{res}=1res=1），第二趟发现 L−d1=2<3L-d_1=2 < 3L−d1​=2<3 再次累加（res=2>M=1\text{res}=2 > M=1res=2>M=1），误返回 false。正确结果应为移走唯一岩石，跳跃距离 444。

    Hack 2（代码审查发现，触发第三趟 bug）：
