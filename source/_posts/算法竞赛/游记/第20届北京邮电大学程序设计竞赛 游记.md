我们开始猜测题目含义，猜测题目难度。我队友：“E 题这个简单的字符串问题真的简单吗”，我：“这种话你也信啊，出题人的话你也信。”没想到这真的是签到题，失算了。
开赛，读题，队友对各种名词如”整除“，”取余“，”闭区间“，”子字符串“感到好奇，虽然我都认识，但他们还是去翻字典了，查字典也是 ICPC 的一大乐趣，哈哈。  
然后我看了一下电脑上的 A 题，迅速翻译出了 A 题中对十的幂次整除取模的含义，总结出了题意：

- **网络预选赛 A good prime**：给定询问数 $T$（$T\le 10^6$）与 $T$ 个区间 $[l,r]$（$1\le l\le r\le 5\times10^7$），统计区间内满足「十进制表示中存在某个连续数字子串为素数」的整数 $x$ 的个数。

我想着先用线性筛把质数全找出来，然后对于每一个数，判断他有没有质数子串，最多也就是两个 log。最后做一个前缀和，对每个询问求一个差就好了。总的复杂度应该是线性乘一个不大常数（我设定为 8 * 8 = 64 了，10 的 0~7 次幂共 8 位），而且跑不满，看了一下两秒的时限，应该可以过。然后就开始写代码，从蓝书上抄了一个线性筛的板子，让队友去看后面的题了。  
第一次提交 A 题，把线性筛的上限写成 1e7 了，WA，之后一直 TLE。断定为系统卡常，开始尝试优化。想了各种卡常办法，把输入输出换成了 `scanf/printf`，等等，均未通过。我看排行榜，发现一小时仍然无人通过 A 题，反而是 B 题和 E 题有通过，判断系统卡常过于严重，遂保存代码开 B 题，队友告诉了我题意：

- **网络预选赛 B MystPal**：给定长度 $n$（$n\le10^6$，$T\le10^5$ 次询问），统计长度为 $n$ 的 `0/1` 串中「是回文、且其二进制值能被 $3$ 整除」的串数，答案对 $998244353$ 取模。

然后数竞背景的队友告诉我用费马小定理转换，等价于奇数位置上的 1 和偶数上的 1 的个数相等。然后他们分析出了偶数长度的字符串都可取，我得出答案就是 $2^\frac{n}{2}$，队友提醒我取模，我去蓝书上抄了一个快速幂取模的板子。然后我们开始推奇数的公式，我按 $k = \frac{n - 1}{2}$ 的奇偶给出了两组组合数求和，让数竞的队友想想这个东西怎么算，我指出这个东西可能要用范德蒙德卷积，但是我不记得公式了，队友指出他没听说过，于是我们开 E 题。  

- **网络预选赛 E Maybe an Easy String Problem**：给定字符串 $s$ 与 $q$ 次询问 $[l,r]$（$n,q\le10^6$），求子串 $s[l,r]$ 内**出现次数最多的子串**的出现次数。

队友问我单个字母算不算子串，我说，你看第四个样例呗，区间长度为 $2$ 的询问答案都为 $1$ 了，你说算不算。我：“这倒是提醒我了”，子串的重复个数，肯定不多于里面某个字母的重复个数，那这不就是问出现最多的字母出现了多少次吗，字母就 $26$ 个小写字母，那直接开 $26$ 棵线段树呗。队友说，他之前学过的最高级的数据结构就是线段树了，现在已经忘了。我说，等下这个东西又不用修改，那直接开 $26$ 个前缀和不就是了，于是迅速写出了代码。然后又 TLE，我草，$O(cn)$ 的复杂度怎么可能还不对哦，发现忘记把板子上的关同步流抄上去了，遂换 `scanf`，又交，又 TLE，发现忘记写 `printf` 了。然后总算过了。看了一下排名，跟队友说进正赛肯定稳了，大家非常开心。  
接下来我们讨论 B 题的公式，我让他们考虑一下组合意义，因为每一个复杂的组合恒等式背后，都蕴含着一个简洁的组合意义。然后他们在思考，我去接着卡 A 题的常数。
我把末尾为 ${2,3,5,7}$ 的数字去掉了，减少了 $40\%$ 的计算量，然后又把十位是这些数的去掉了，继续减少计算量，但都未通过。我：“你们帮我在草稿纸上默写一下 $0 \sim 100$ 的质数”，两位队友争着抢着做，说总算找到了一些真的会做的事了。然后我把含 $2,3,5,7$ 的划掉，剩了 5 个，把这几个结尾的数也去掉，本地预处理所用的时间从 $2300ms \rightarrow 1800ms \rightarrow 1100ms \rightarrow 800ms$ ，还是无法通过。于是我放弃抵抗，对评测机破口大骂。

```cpp
#include <bits/stdc++.h>
using namespace std;
// #define int long long
const int N = 5e7;
int v[N + 5], prime[N/ 10];
int f[N + 5], po[10] = {1};

int m;
void primes(int n)
{
    for (int i = 2; i <= n; i++)
    {
        if (v[i] == 0) // i is prime
        {
            v[i] = i;
            prime[++m] = i;
        }
        for (int j = 1; j <= m; j++)
        {
            if (prime[j] > v[i] || prime[j] > n / i)
                break;
            v[i * prime[j]] = prime[j];
        }
    }
}

void dfs(int x, bool pr = 0)
{
    if (x > N)
        return;
    for (int j = 0; !pr && po[j] <= x * 10; j++)
        pr |= (v[x % po[j]] == (x % po[j])) && (x % po[j]);
    if (pr)
        f[x] = 1;
    for (int i = 0; i <= 9; i++)
    {
        int nxt = x * 10 + i;
        if (nxt)
            dfs(nxt, pr);
    }
}

void solve()
{
    int l, r;
    scanf("%d %d", &l, &r);
    printf("%d\n", f[r] - f[l - 1]);
}

signed main()
{
#ifdef DEBUG
    clock_t t0 = clock();
    freopen("input.txt", "r", stdin);
    freopen("data.ans", "w", stdout);
#endif

    // you have so much time
    // tomorrow yet to come
    // you deserve more love

    for (int i = 1; i <= 9; i++)
        po[i] = po[i - 1] * 10;

    dfs(0);
    for (int i = 1; i <= N; i++)
        f[i] += f[i - 1];

    int q;
    scanf("%d", &q);
    while (q--)
    {
        int l, r;
        scanf("%d %d", &l, &r);

#ifdef DEBUG

}
```

- **正式赛 K Seeing is believing**：这是一道交互题——你被困在一个 $n\times n$、格子为 `.` 或 `#` 的漆黑迷宫（起点 $(1,1)$，终点 $(n,n)$，保证连通），通过尝试朝上下左右移动并读取返回的 $1$（成功）/ $0$（撞墙或出界）来探路，**移动尝试总数不得超过 $2n^2$**（$2\le n\le 500$）；收集足够信息后输出 `!`，随后输出从 $(1,1)$ 到 $(n,n)$ 的最短路径（由 `W/A/S/D` 组成），若步数超限、路径不合法或非最短都判错。
- **正式赛 N XOR**：给定长度为 $n$ 的非负整数序列 $A=\{a_1..a_n\}$，定义序列值为 $\sum_{i=1}^{n-1}(a_i\oplus a_{i+1})$；至多可以执行一次操作：选整数 $X$（$0\le X<2^{30}$）与区间 $[l,r]$，把 $a_l..a_r$ 全部异或 $X$；求操作后序列值的最大值。多组数据 $T$（$1\le T\le 10^4$），$1\le n\le 2\times10^5$ 且 $\sum n\le 2\times10^5$，$0\le a_i<2^{30}$。
